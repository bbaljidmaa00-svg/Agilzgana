# Agilzgana вэбсайт

Гараар, захиалгаар урладаг үнэт эдлэлийн сайт. Cloudflare Workers дээр ажиллана:
- **Сайт** (`public/`): ургадаг угалз, кино шиг нээлт, цуглуулга, хэмжээ оруулах, захиалга, "өөрийн санаагаар захиалах" форм.
- **Админ** (`public/admin/`, хаяг нь `/admin/`): бүтээл нэмэх, засах, нуух, устгах, зураг оруулах, ирсэн захиалгыг харах, төлөв солих.
- **Сервер** (`src/`): `/api/*` хүсэлтүүдийг хариулна. Бүтээл, захиалга нь **D1** өгөгдлийн санд, зургууд нь **KV**-д хадгалагдана.

## Cloudflare тохиргоо

`wrangler.jsonc` дотор бүх тохиргоо бий. GitHub-д push хийхэд Cloudflare Workers Builds `npx wrangler deploy` ажиллуулж,
dashboard дээр үүсгэсэн D1 `agilzgana-db` (`DB`), KV `agilzgana-images` (`IMAGES`)-тэй холбогдоно.

Гараар хийх ганц алхам бол **админы нууц үг**:
Workers & Pages → `agilzgana` → Settings → **Variables and Secrets → Add** → Type = *Secret*, Name = `ADMIN_PASSWORD`, Value = өөрийн нууц үг → Deploy.

Өгөгдлийн сангийн хүснэгтүүд анх ашиглахад автоматаар үүсч, 8 жишээ бүтээл орно. Жинхэнэ бүтээлээ оруулаад жишээнүүдийг админаас устгана.

## Админ

`https://<таны-сайт>/admin/` руу орж нууц үгээрээ нэвтэрнэ. Утаснаас ч ажиллана.
- **+ Шинэ бүтээл**: зураг (12 хүртэл, эхнийх нь нүүр зураг), нэр, төрөл, үнэ, материал, тайлбар. Зургийг браузер дээр нь жижигрүүлээд хадгалдаг тул утасны том зураг ч хурдан орно.
- **Онцлох** нь бүтээлийг эхэнд "Шинэ" тэмдэгтэй гаргана. **Нуух** нь сайтаас түр нууна.
- **Захиалга** табад сайтаас ирсэн бүх захиалга, санаагаар хийлгэх хүсэлт (хавсаргасан зурагтай) харагдана. Төлөвийг Шинэ → Хийж байна → Бэлэн → Хүргэсэн гэж сольно.

Үйлчлүүлэгч захиалга өгөхөд захиалга өгөгдлийн санд хадгалагдаж, мөн захиалгын текстийг Instagram DM-ээр илгээх товч гарна.

## Локалаар ажиллуулах

```sh
echo 'ADMIN_PASSWORD=test' > .dev.vars
npx wrangler dev
```

## Хууль, нууцлал, хүртээмж

- **Бизнесийн мэдээлэл**: `public/business.js` дотор хуулийн нэр, бүртгэлийн дугаар, хаяг, имэйл, утсаа бөглөнө. Бөглөөгүй талбар сайт дээр шар "[бөглөх: ...]" тэмдэгтэй харагдана.
- **Бодлогууд**: `privacy.html`, `terms.html`, `cookies.html`, `refund.html`, `about-business.html`. Шар "[бөглөх: ...]" хэсгүүдийг (төлбөр, хүргэлт, урьдчилгаа) бөглөнө. Бодлого өөрчилбөл `business.js` дахь `policyDate`-ийг шинэчилнэ.
- **Зөвшөөрөл**: захиалга, санааны формыг зөвшөөрлийн нүд тэмдэглэхгүйгээр илгээх боломжгүй; зөвшөөрсөн огноо, бодлогын хувилбар захиалгатай хамт хадгалагдана (админд харагдана).
- **Хадгалах хугацаа**: нууцлалын бодлогод захиалгыг дууссанаас хойш 1 жил, захиалга болоогүй санааг 6 сар хадгална гэж бичсэн. Хугацаа нь дуусахад админаас **гараар устгана** (устгахад хавсаргасан зураг хамт устана).
- **Фонт**: `public/fonts/`-оос өөрсдөө ачаална (SIL OFL), Google руу хүсэлт явахгүй.
- **Аналитик, пиксел нэмэх бол** эхлээд күүкиний зөвшөөрлийн цонх нэмж, `cookies.html`-ийг шинэчилнэ.
